# بررسی امنیت و منابع نیل منجر — ۱۱ آبان ۱۴۰۵

مبنای بررسی: نسخهٔ **۱.۱۱.۳**، کد منتشرشده و محیط دموی مستقل با WordPress 7.1.4، WooCommerce 11.2.1، PHP 8.3.36 و MySQL 8.0.46. کد اجرایی افزونه در این بررسی تغییر نکرد و انتشار تازه ساخته نشد. فروشگاه اصلی و داده‌های مشتریان در آزمون استفاده نشدند.

## نتیجهٔ منابع

دو محصول متغیر ساختگی با ۲ و ۴۰ ورییشن خصوصی ساخته شدند. فهرست هرکدام سه مرتبه خوانده شد؛ فقط کش همان محصولات پیش از هر خواندن پاک شد، بدون پاک‌کردن کش سراسری هاست. پس از آزمون، همهٔ محصولات و کاربر ساختگی حذف شدند.

| فهرست یک والد و ورییشن‌هایش | ۲ ورییشن | ۴۰ ورییشن |
|---|---:|---:|
| ردیف برگشتی | ۳ | ۴۱ |
| کوئری‌ها، سه اجرا | ۱۱، ۱۰، ۱۰ | ۱۰، ۱۰، ۱۰ |
| میانهٔ زمان عملیات | ۶٫۱۸ ms | ۵۰٫۳۹۹ ms |
| میانهٔ زمان CPU فرایند PHP | ۳٫۹۲۲ ms | ۴۴٫۳۶۱ ms |
| بیشترین افزایش اوج حافظهٔ PHP | ۱۴۴٬۸۴۰ بایت | ۱٬۳۹۱٬۵۵۲ بایت |

تعداد کوئری‌ها با تعداد ورییشن‌ها رشد خطی نداشت. زمان و حافظه با تعداد داده افزایش یافتند، اما این نمونهٔ محدود زیر ۱٫۴ مگابایت افزایش اوج حافظه داشت. این اعداد مربوط به عملیات فهرست در همین محیط‌اند؛ کل رم وردپرس، RSS، درصد CPU هاست، بار هم‌زمان یا امتیاز سرعت فروشگاه اندازه‌گیری نشده‌اند.

- فراخوانی خود تابع آغاز افزونه در محیط بارگذاری‌شده، **صفر SQL اضافه** اجرا کرد؛ این عدد کل کوئری‌های راه‌اندازی وردپرس نیست.
- در صفحهٔ مدیریت نامرتبط، فایل مدیریت افزونه بارگذاری نشد.
- بررسی ساخت: مجموع CSS و JavaScript مدیریت **۵۹٬۸۹۸ بایت**؛ اسکریپت اختیاری تخفیف پرداخت **۱٬۱۸۳ بایت** و محدود به تسویه‌حساب با قابلیت فعال است. فونت محلی جدا از این مجموع است.
- پیش‌نمایش، ذخیره، گزارش، فایل و تصویر سقف‌های دسته، تعداد، حجم و حافظه دارند. اسکن رسانه فقط با اقدام صریح اجرا می‌شود. سابقهٔ بازگردانی عمداً نگهداری می‌شود و حذف خودکار اطلاعات گزارش اضافه نشده است.

## کنترل‌های امنیتی

**۳۵ بررسی در محیط واقعی دمو موفق شد**: جلوگیری از دسترسی ناشناس و مشترک به ۱۳ مسیر حساس برای هر نقش، اعتبارسنجی nonce درست/غلط/غایب با تابع اصلی وردپرس، کنترل منابع و حفظ کامل ورییشن‌ها. کاربر آزمایشی حذف شد. دسترسی عمومی دمو به‌صورت جدا نیز بر اساس مالکیت نشست محدود است.

بازبینی کد شامل SQL پارامتری و شناسه‌های عددی، کنترل مالکیت عملیات و دسترسی محصول و والد، خروجی HTML و DOM، مسیرهای محلی رسانه، محدودیت CSV/XLSX و XML، درخواست‌های خارجی با میزبان ثابت و سقف پاسخ، و اعتبار اندازه و SHA-256 بستهٔ بروزرسان بود. اجرای shell، eval یا unserialize برای ورودی کاربر در کد اجرایی افزونه استفاده نشده است.
